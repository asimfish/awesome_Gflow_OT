# 实验 · 第 1 天：精确 LP 验证 O08 的结构性事实

对应 `reports/INSIGHTS.md` §6c 第 1 天。全部精确求解（`scipy.optimize.linprog`, HiGHS），无学习；脚本 `experiments/day1_reference_lp.py`，结果 JSON 在 `experiments/results/`。

## 设定

- 状态图：hypergrid \(\{0,\dots,H-1\}^2\)，双向 ±1 转移（有环），单位边代价；\(H\in\{10,15,20\}\)。
- 源分布 \(L\)：O08 Appendix B.1 形式的 ball / moon（\(r_{\text{out}}=0.3,\ r_{\text{in}}=0.2,\ \delta=0.12,\ \varepsilon=10^{-3}\)）；目标 \(R\)：corner-shaped（\(R_0/R_1/R_2=10^{-3}/0.5/2\)）。**O08 未公布这些超参与 \(D\)，所以这里的数字不是 Table 1 的复现，只检验恒等式与反例。**
- 最小流 LP：\(\min\sum_e F(e)\) s.t. \(\operatorname{div}F=L-R\)（O08 Eq. (11)）；Kantorovich：耦合 LP，代价 = 跳数距离。

## 读法

1. **GFlow* = OT* 在六个配置上精确成立**（差 \(\le4\times10^{-14}\)）——这是 O08 Thm. 3.2 在多源、有环 hypergrid 上的数值验证；HiGHS 返回的等式对偶 \(\pi\) 在所有内部边上满足 \(\pi_{s'}-\pi_s\le1\)（最大违反 0），互补松弛 \(F(e)\,(1-(\pi_{s'}-\pi_s))=0\) 逐边成立——对应 O08 Appendix A.4 的扩展对偶（多源），不是 Thm. 3.3 的单源版本。
2. **反例 1（INSIGHTS §6b）成立**：把源按「离得最远」配对并沿最短路运输，divergence 残差与最优解一样是 \(10^{-15}\) 量级，代价却高 60–75%。**balance 残差为零不认证最优性**；同一个对偶势下的 gap（3.4–7.9）立刻把它判出来。
3. **反例 2 成立**：保持最优耦合不变、每份质量经一个远处路点绕行，端点耦合代价仍等于 OT*，执行代价升到 2.5–3.5 倍，残差仍为零。**认证端点耦合的代价 ≠ 认证策略执行代价**；O08 Table 1 报的 \(\mathbb E|\tau|\) 是执行代价。
4. 由此，一个只看 balance 残差的「证书」在两类错误面前都是盲的；能同时判出两者的是**弱对偶 gap**（对可行流）——这决定了课题①的证书必须以对偶势为核心。
